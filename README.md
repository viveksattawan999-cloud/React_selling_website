# NovaStore React Selling Website

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Included
- React + Vite SPA
- React Hooks (`useState`, `useEffect`, `useMemo`)
- Light/dark mode with CSS variables
- Product search, category filtering, sorting
- Slide-out cart with quantity controls
- Multi-step demo checkout modal
- Dummy product data in `src/data/products.json`
- Responsive design
- No `node_modules` included
